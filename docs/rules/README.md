# Rules — readable versions

These markdown files are **reference only**. The rules the engine runs are
the YAML files in `rules/` (same folder names). When a rule changes, its
YAML is changed; a file here may be out of date.

- `payroll/`, `special-instructions/`, `validation/`, `compliance/` — the
  first written versions of each rule, in words.
- `case-types/` — what each case type means and which rules it affects.
- `old/` — the very first drafts, before the rules were split by agent.
